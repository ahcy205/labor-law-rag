## 2026-11-17 uv와 Python 3.12
- 결정: 패키지 · Python 버전 관리는 uv로 하고, Python은 3.12로 고정한다(`.python-version`).
- 이유: PC에는 Python 3.14만 있다. 계획 2~3에서 쓸 torch · 형태소 분석기 휠은 3.12에서 가장 안정적이다. uv는 lock 파일로 재현성을 보장한다.
- 틀렸을 때 비용: 낮음. `.python-version`과 lock만 바꾸면 된다.

## 2026-11-17 데이터 파일의 git 관리
- 결정: `data/raw/`, `data/processed/`, `data/heldout/`은 git에서 뺀다. `data/eval/`, `data/manifest.json`, `results/`는 커밋한다.
- 이유: 원본 크기를 아직 모른다. 수집 스크립트와 캐시로 같은 기준일 데이터를 다시 만들 수 있다(설계 3.4). 평가 세트와 결과는 이 프로젝트의 핵심 산출물이다.
- 틀렸을 때 비용: 낮음. 크기를 본 뒤 다시 판단한다.

## 2026-11-17 Ollama 출력 토큰 상한과 주소
- 결정: `OllamaClient`는 `num_predict=1024`를 기본으로 보낸다. `localhost`는 `127.0.0.1`로 바꿔 요청한다.
- 이유: JSON 형식을 강제하면 qwen3:8b가 문자열 값을 끝없이 이어 써서 응답이 오지 않았다(상한 없이 80초 넘게 대기, 300토큰 상한에서는 `done_reason=length`). 잘린 출력은 JSON 검증에 실패하므로 재시도로 처리된다. Windows에서 `localhost`는 IPv6를 먼저 시도해 요청마다 약 2초가 더 걸렸다.
- 확인: 짧은 JSON 요청에 exaone3.5:7.8b는 5초, qwen3:8b는 24초가 걸렸다(qwen3는 재시도가 섞였을 수 있음). 초안 프롬프트에서 질문 길이 제한을 분명히 적는다.
- 틀렸을 때 비용: 긴 출력이 필요한 작업(답변 생성)은 상한을 늘려야 한다. 인자로 바꿀 수 있다.

## 2026-11-17 국가법령정보 OPEN API 요청 형식 (Task 4)
- 목록: `https://www.law.go.kr/DRF/lawSearch.do?OC=..&target=eflaw&type=XML&query=<법령명>&display=100&page=N`
  - 응답 `law` 항목의 필드: `법령명한글`, `법령일련번호`(MST), `현행연혁코드`(현행/시행예정/연혁), `시행일자`, `공포일자`.
  - 검색어가 들어간 다른 법령(시행령 · 시행규칙, 띄어쓰기 없는 옛 이름)도 섞여 나오므로 이름이 정확히 같은 것만 쓴다.
  - 근로기준법은 시행 예정 버전(2026-12-08, 2027-01-01 등)이 목록에 함께 나온다. 그래서 `시행일자 <= 기준일` 중 가장 늦은 것을 고르고, 같으면 공포일자가 늦은 것을 고른다.
- 본문: `lawService.do?OC=..&target=eflaw&type=XML&MST=<법령일련번호>&efYd=<시행일자>`
  - 구조: `법령/기본정보`(`법령명_한글`, `시행일자`), `법령/조문/조문단위`(`조문번호`, `조문가지번호`, `조문여부`=조문|전문, `조문제목`, `조문내용`, `조문시행일자`, `항`/`항번호`/`항내용`/`호`/`호내용`/`목`/`목내용`), `법령/별표/별표단위`.
  - 받은 본문 9개에서 `조문시행일자`가 기준일보다 늦은 조문은 없었다.
- 오류도 HTTP 200으로 온다: `<Response><result>사용자 정보 검증에 실패하였습니다.</result>`(OC · IP 미등록), `<Law>일치하는 법령이 없습니다.</Law>`. 이런 본문은 캐시에 남기지 않는다.
- 계획에 없던 구조: (1) 항 번호 없는 `<항>` 안에 호만 있는 조(예: 근로기준법 제26조)는 조 단위 근거로 묶는다. (2) 항 단위 삭제(`③ 삭제 <2017.11.28>`)는 텍스트와 근거에서 뺀다. (3) 본문의 `<개정 2012.2.1>` 같은 개정 표시는 원문 그대로 둔다.
- fixture에 OC가 섞이지 않도록 `tests/test_fixtures_clean.py`가 검사한다.

## 2026-11-17 말뭉치 확정과 평가용 원문 떼기 (Task 8)
- 결정: 문서의 첫 주제(층화 기준)는 안건명에 맞는 주제를 먼저 둔다. 본문에만 맞는 주제는 그 뒤에 둔다.
